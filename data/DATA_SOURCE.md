# Healthcare Dataset Source

## Dataset Name

Diabetes 130-US Hospitals for Years 1999–2008

## Source

UCI Machine Learning Repository

Dataset link: https://archive.ics.uci.edu/dataset/296/diabetes+130-us-hospitals+for+years+1999-2008

## Dataset Overview

This dataset contains hospital encounter records relating to patients with diabetes from 130 US hospitals over the period 1999–2008.

It includes information such as:
- Patient demographics
- Hospital admission and discharge details
- Diagnoses
- Laboratory procedures
- Medications
- Length of hospital stay
- Readmission outcomes

## Project Use

This dataset will be used for educational purposes to demonstrate healthcare data ingestion, cleaning, transformation, data quality checks, SQL analytics, and dashboard development using Microsoft Fabric.

## Data Handling

- The original dataset will not be uploaded to this repository unless redistribution is permitted by its applicable terms.
- The source will be credited in project documentation.
- Data quality limitations and analytical assumptions will be documented.
- Findings will be interpreted responsibly and will not be presented as clinical advice.
